🌱 EcoSwap – Sustainable Marketplace (CLI Version)

EcoSwap is a mini Python-based marketplace where users can buy and sell pre-owned items, supporting sustainable consumption.
This project demonstrates Python CLI programming, SQLite database usage, and basic CRUD operations.

✨ Features :
- Add items for sale (name, category, price, condition)
- View all available items
- Search items by category
- Send messages to sellers
- Data stored in SQLite database (ecoswap.db)
- Clean, modular Python code (main.py, marketplace.py, database.py)

🛠 Technologies Used : 
  1. Python 3.x
  2. SQLite3 (built-in Python module)
  3. Command Line Interface (CLI)
